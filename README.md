# BankNilami Elevate

Build a premium, modern, highly professional corporate website for **BankNilami.com — Auction Information Hub**, managed by **Citiline Technologies Private Limited**.

The website should be built as a production-quality responsive web application using:

* Next.js
* TypeScript
* Tailwind CSS
* shadcn/ui
* Modern reusable component architecture
* Fully responsive design for desktop, tablet and mobile
* SEO-friendly structure
* Fast-loading and performance optimized pages
* Clean animations and micro-interactions
* Professional financial-services / institutional visual language

IMPORTANT:
This is NOT a generic real-estate website. BankNilami.com is a professional **bank property auction management and realisation platform** serving Banks, NBFCs, HFCs, Small Finance Banks and Co-operative Banks. The design should communicate trust, compliance, transparency, scale and institutional credibility.

# AUCTION & REALISATION JOURNEY

Create one of the main visual sections of the website.

Heading:
**The Auction & Realisation Journey**

Subheading:

“We manage the property auction journey end to end — from valuation and readiness through to final proceeds settlement — with complete visibility at every stage.”

Create a horizontal timeline on desktop and vertical timeline on mobile.

Six stages:

01
**Valuation & Pre-Auction Readiness**

Independent valuation support, title & documentation checks, and reserve-price benchmarking on the bank's secured property.

02
**Auction Planning & Execution**

End-to-end auction planning — notice drafting, statutory publication, timelines and process design aligned to SARFAESI / DRT norms.

03
**Market Outreach & Buyer Discovery**

Wide marketing campaigns, digital listing on bankNilami.com, and buyer network activation to maximise footfall and genuine bids.

04
**Bid Management & Transparent Bidding**

Structured bid management, e-auction / physical auction support, and fair, auditable bidding for every stakeholder.

05
**Sale Confirmation & Buyer Coordination**

Confirmation of sale, buyer documentation support and coordination for timely completion of the transaction.

06
**Realisation, Proceeds & Account Settlement**

Proceeds tracking, reconciliation, MIS & realisation reporting, and account settlement support back to the bank.

Make this section highly visual with connecting lines, numbered steps and icons.
